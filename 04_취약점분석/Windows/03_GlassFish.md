# GlassFish Directory Traversal 취약점 분석

## 개요

GlassFish는 Java EE 기반 애플리케이션 서버로 웹 애플리케이션 운영에 사용된다.

진단 과정에서 GlassFish 관리 인터페이스가 외부에 노출되어 있었으며, 특정 경로 조작을 통해 서버 내부 파일에 접근할 수 있는 Directory Traversal 취약점을 확인하였다.

본 취약점은 공격자가 서버 내부 설정 파일 및 중요 정보를 획득할 수 있는 위험성을 가진다.

---

## 취약점 정보

| 항목 | 내용 |
|--------|--------|
| 서비스 | GlassFish |
| 포트 | 4848/TCP |
| 유형 | Directory Traversal |
| 위험도 | High |
| 영향 | 중요 시스템 파일 열람 가능 |

---

## 서비스 식별

Nmap 스캔 결과 GlassFish 관리 서비스가 확인되었다.

```bash
nmap -sV 10.0.0.41
```

### 확인 결과

```text
4848/tcp open http
GlassFish Server Open Source Edition
```

---

## 취약점 확인

GlassFish 서비스에 대한 공개 취약점을 조사하던 중 Directory Traversal 취약점이 존재함을 확인하였다.

특정 경로를 조작하여 웹 루트 외부의 파일에 접근 가능한지 검증하였다.

---

## 검증 결과

시스템 파일인 win.ini 파일 읽기에 성공하였다.

### 확인 가능 정보

- 운영체제 정보
- 시스템 설정 정보
- 추가 파일 접근 가능성 확인

이는 공격자가 중요 설정 파일이나 계정 정보를 포함한 파일에 접근할 수 있음을 의미한다.

---

## 공격 가능성 분석

Directory Traversal 취약점은 직접적인 코드 실행으로 이어지지 않더라도 공격자가 내부 구조를 파악하는 데 활용될 수 있다.

특히 다음과 같은 정보 획득이 가능하다.

- 시스템 설정 파일
- 애플리케이션 설정 파일
- 계정 정보
- 데이터베이스 접속 정보

획득한 정보를 기반으로 추가 공격이 가능하다.
