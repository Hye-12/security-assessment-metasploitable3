# MySQL 기본 계정 및 인증 정책 취약점 분석

## 개요

MySQL은 데이터 저장 및 관리를 위해 널리 사용되는 관계형 데이터베이스 관리 시스템(RDBMS)이다.

진단 과정에서 MySQL 서비스가 외부에서 접근 가능하였으며, 기본 계정에 비밀번호가 설정되지 않은 상태를 확인하였다.

이러한 취약한 인증 정책은 공격자가 데이터베이스에 무단 접근하여 중요 정보를 조회하거나 변경할 수 있는 위험을 가진다.

---

## 취약점 정보

| 항목 | 내용 |
|--------|--------|
| 서비스 | MySQL |
| 포트 | 3306/TCP |
| 유형 | 기본 계정 및 취약한 인증 정책 |
| 위험도 | High |
| 영향 | 데이터베이스 무단 접근 가능 |

---

## 서비스 식별

Nmap 스캔 결과 MySQL 서비스가 활성화되어 있음을 확인하였다.

```bash
nmap -sV 10.0.0.41
```

### 확인 결과

```text
3306/tcp open mysql
MySQL
```

---

## 취약점 확인

MySQL 접속을 시도한 결과 기본 계정(root)에 비밀번호가 설정되어 있지 않은 상태를 확인하였다.

이를 통해 인증 절차를 우회하지 않고도 데이터베이스 접근이 가능하였다.

### 확인 내용

- root 계정 사용 가능
- 비밀번호 미설정
- 데이터베이스 조회 가능

---

## 공격 가능성 분석

공격자가 데이터베이스에 접근할 경우 다음과 같은 행위가 가능하다.

- 사용자 정보 조회
- 중요 데이터 유출
- 데이터 변조
- 계정 정보 확보
- 추가 시스템 침투를 위한 정보 수집

특히 데이터베이스 내 저장된 계정 정보와 서비스 설정 정보는 추가 공격의 발판으로 활용될 수 있다.
