# Elasticsearch 취약점 분석

## 개요

Elasticsearch는 대용량 데이터 검색 및 분석을 위한 오픈소스 검색 엔진이다.

진단 과정에서 Elasticsearch 서비스가 외부에 노출되어 있었으며, 버전 정보 및 공개 취약점 조사를 통해 원격 코드 실행(Remote Code Execution) 가능성을 확인하였다.

본 취약점은 인증 없이 시스템 명령 실행 및 서버 장악으로 이어질 수 있어 높은 위험도를 가진다.

---

## 취약점 정보

| 항목 | 내용 |
|--------|--------|
| 서비스 | Elasticsearch |
| 포트 | 9200/TCP |
| 유형 | 원격 코드 실행(RCE) |
| 위험도 | Critical |
| 영향 | 시스템 권한 획득 가능 |

---

## 서비스 식별

Nmap 스캔 결과 Elasticsearch 서비스가 확인되었다.

```bash
nmap -sV 10.0.0.41
```

### 확인 결과

```text
9200/tcp open http
Elasticsearch
```

---

## 취약점 확인

웹 브라우저 및 서비스 응답 분석을 통해 Elasticsearch 버전 정보를 확인하였다.

확인된 버전을 기반으로 공개 취약점(CVE)을 조사한 결과 원격 코드 실행이 가능한 취약점이 존재함을 확인하였다.

---

## 위험성 분석

Elasticsearch는 기본적으로 대량의 데이터를 저장하고 검색하는 역할을 수행한다.

공격자가 취약점을 악용할 경우 다음과 같은 행위가 가능하다.

- 시스템 명령 실행
- 중요 데이터 조회
- 악성코드 업로드
- 추가 내부망 공격 수행

특히 인증 우회와 결합될 경우 서버 전체 장악으로 이어질 수 있다.

---

## 공격 가능성 분석

공개된 취약점을 이용하여 원격 코드 실행이 가능함을 확인하였다.

본 프로젝트에서는 실제 침투 단계에서 해당 취약점을 활용한 시스템 접근 가능성을 검증하였다.

※ 상세 공격 과정은 "05_초기침투/Windows" 문서에서 별도로 기술한다.
