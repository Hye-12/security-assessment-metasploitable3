# SMB (MS17-010) 취약점 분석

## 개요

MS17-010(EternalBlue)은 Microsoft SMBv1 프로토콜의 원격 코드 실행(Remote Code Execution) 취약점으로, 공격자가 인증 없이 원격에서 임의의 코드를 실행할 수 있는 취약점이다.

본 진단에서는 Metasploitable3 Windows Server 2008 R2 환경을 대상으로 SMB 서비스의 취약 여부를 확인하고 공격 가능성을 검증하였다.

---

## 취약점 정보

| 항목 | 내용 |
|--------|--------|
| 서비스 | SMB |
| 포트 | 445/TCP |
| 취약점 | MS17-010 (EternalBlue) |
| CVE | CVE-2017-0144 |
| 위험도 | Critical |
| 영향 | 원격 코드 실행(RCE), 시스템 장악 가능 |

---

## 서비스 식별

Nmap 스캔 결과 SMB 서비스가 활성화되어 있음을 확인하였다.

```bash
nmap -sV 10.0.0.41
```

### 확인 결과

```text
445/tcp open microsoft-ds
```

---

## 취약점 확인

Nessus 및 OpenVAS 진단 결과 대상 시스템에서 MS17-010 취약점이 탐지되었다.

해당 취약점은 SMBv1 처리 과정의 결함으로 인해 인증 없이 원격 코드 실행이 가능한 심각한 취약점이다.

### 위험성

- 인증 우회 가능
- 원격 코드 실행 가능
- 관리자 권한 획득 가능
- 랜섬웨어 확산 악용 가능

대표적으로 WannaCry 랜섬웨어가 해당 취약점을 악용하였다.

---

## 공격 가능성 분석

MS17-010 취약점이 존재할 경우 공격자는 네트워크 접근만으로 시스템에 대한 원격 공격을 수행할 수 있다.

특히 별도의 계정 정보 없이 공격이 가능하며 성공 시 시스템 전체 권한 획득으로 이어질 수 있다.

본 프로젝트에서는 실제 침투 검증 단계에서 해당 취약점을 이용한 시스템 접근 가능성을 확인하였다.

※ 실제 공격 과정은 "05_초기침투/Windows" 문서에서 별도로 기술한다.

---

## 영향

### 기밀성 (Confidentiality)

- 시스템 내부 정보 노출
- 계정 정보 유출 가능

### 무결성 (Integrity)

- 파일 변조 가능
- 악성코드 설치 가능

### 가용성 (Availability)

- 시스템 장애 유발 가능
- 랜섬웨어 감염 가능

---

## 보안 대책

### 패치 적용

MS17-010 보안 패치를 적용하여 SMB 취약점을 제거한다.

### SMBv1 비활성화

사용하지 않는 SMBv1 프로토콜을 비활성화한다.

### 접근 통제

방화벽을 이용하여 SMB 포트(445/TCP)에 대한 접근을 제한한다.

### 취약점 점검

정기적인 취약점 진단을 수행하여 패치 적용 여부를 확인한다.
