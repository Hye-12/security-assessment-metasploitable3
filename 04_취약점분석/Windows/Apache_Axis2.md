# Apache Axis2 취약점 분석

## 개요

Apache Axis2는 웹 서비스(Web Service)를 제공하기 위한 SOAP 기반 프레임워크이다.

진단 과정에서 Axis2 관리 페이지가 외부에 노출되어 있었으며 기본 계정을 이용한 접근이 가능함을 확인하였다.

본 취약점은 관리 기능 악용 시 원격 코드 실행(Remote Code Execution)으로 이어질 수 있어 높은 위험도를 가진다.

---

## 취약점 정보

| 항목 | 내용 |
|--------|--------|
| 서비스 | Apache Axis2 |
| 포트 | 8282/TCP |
| 위험도 | High |
| 유형 | 취약한 인증 정책 |
| 영향 | 관리자 페이지 접근 및 원격 코드 실행 가능 |

---

## 서비스 식별

Nmap 스캔 결과 Apache Axis2 서비스가 확인되었다.

```bash
nmap -sV 10.0.0.41
```

### 확인 결과

```text
8282/tcp open http
Apache Axis2
```

---

## 취약점 확인

웹 브라우저를 통해 Axis2 관리 페이지에 접근하였다.

관리 콘솔이 외부에 노출되어 있었으며 기본 계정을 이용한 로그인이 가능하였다.

### 확인 내용

- 관리자 페이지 외부 노출
- 기본 계정 사용
- 접근 제한 미구성

---

## 공격 가능성 분석

관리자 페이지 접근이 가능할 경우 서비스 업로드 기능을 악용하여 악성 파일 배포 및 원격 코드 실행이 가능하다.

또한 공격자가 시스템 권한으로 명령을 실행할 가능성이 존재한다.

본 프로젝트에서는 실제 침투 검증 단계에서 해당 취약점을 이용한 시스템 접근 가능성을 확인하였다.

※ 상세 공격 과정은 "05_초기침투/Windows" 문서에서 기술한다.

## 보안 대책

### 기본 계정 제거

기본 제공 계정 사용을 금지한다.

### 접근 제어

### 인증 강화

강력한 비밀번호 정책을 적용한다.

### 불필요 기능 제거
