# IIS HTTP.sys 취약점 분석

## 개요

HTTP.sys는 Microsoft Windows에서 HTTP 요청을 처리하는 커널 모드 드라이버이다.

진단 과정에서 IIS 서비스가 활성화되어 있었으며, HTTP.sys 관련 공개 취약점에 대한 검증을 수행하였다.

해당 취약점은 원격 공격자가 조작된 HTTP 요청을 전송하여 시스템 장애를 유발할 수 있는 서비스 거부(Denial of Service) 취약점이다.

---

## 취약점 정보

| 항목 | 내용 |
|--------|--------|
| 서비스 | IIS (HTTP.sys) |
| 포트 | 80/TCP |
| 유형 | Denial of Service (DoS) |
| 위험도 | Medium |
| 영향 | 시스템 장애 및 서비스 중단 |

---

## 서비스 식별

Nmap 스캔 결과 IIS 웹 서버가 활성화되어 있음을 확인하였다.

```bash
nmap -sV 10.0.0.41
```

### 확인 결과

```text
80/tcp open http
Microsoft IIS
```

---

## 취약점 확인

서비스 버전 및 공개 취약점을 분석한 결과 HTTP.sys 관련 취약점 검증이 가능한 환경임을 확인하였다.

취약점 검증 과정에서 특수하게 조작된 HTTP 요청을 전송하여 서비스 반응을 확인하였다.

---

## 검증 결과

취약점 검증 과정에서 대상 시스템이 비정상 종료(BSOD) 상태에 진입하는 현상을 확인하였다.

이를 통해 공격자가 서비스 중단을 유발할 수 있음을 검증하였다.

---

## 공격 가능성 분석

해당 취약점은 시스템 권한 획득으로 이어지지는 않지만 서비스 운영에 직접적인 영향을 미친다.

공격자는 반복적인 요청을 통해 다음과 같은 영향을 줄 수 있다.

- 웹 서비스 중단
- 업무 서비스 장애
- 시스템 재부팅 유도
- 가용성 저하

---

## 영향

### 기밀성

- 직접적인 영향 없음

### 무결성

- 직접적인 영향 없음

### 가용성

- 서비스 중단 가능
- 시스템 장애 발생 가능
- 업무 연속성 저해

## 보안 대책

### 보안 패치 적용

Microsoft 보안 패치를 최신 상태로 유지한다.

### IIS 최신화

지원 종료 버전 사용을 지양한다.

### 접근 통제

방화벽 및 IPS를 이용하여 비정상 요청을 차단한다.

### 모니터링 강화

비정상 HTTP 요청 발생 여부를 지속적으로 점검한다.
