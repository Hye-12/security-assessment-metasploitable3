# Microsoft FTP 서비스 분석

## 개요

진단 과정에서 Microsoft FTP 서비스가 활성화되어 있는 것을 확인하였다.

익명 로그인 및 파일 접근 가능 여부를 검증하였으며, 서비스 설정 상태를 점검하였다.

---

## 서비스 정보

| 항목  | 내용            |
| --- | ------------- |
| 서비스 | Microsoft FTP |
| 포트  | 21/TCP        |
| 위험도 | Low           |

---

## 확인 내용

* FTP 서비스 활성화 확인
* 익명 로그인 여부 확인
* 파일 접근 권한 점검

---

## 분석 결과

익명 로그인은 허용되지 않았으며, 진단 과정에서 추가적인 취약점은 확인되지 않았다.

다만 FTP 프로토콜은 기본적으로 평문 통신을 사용하므로 운영 환경에서는 보안상 주의가 필요하다.

---

## 보안 대책

* FTP 대신 SFTP 사용 권장
* 불필요한 FTP 서비스 비활성화
* 강력한 인증 정책 적용
* 접근 로그 모니터링 수행

---

## 결론

FTP 서비스는 활성화되어 있었으나 익명 접근 및 직접적인 취약점은 확인되지 않았다. 다만 평문 통신에 따른 위험성을 고려하여 보안 설정을 강화할 필요가 있다.
