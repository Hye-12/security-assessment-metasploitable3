# 프로젝트 소개

## 프로젝트 개요

본 프로젝트는 Metasploitable3 Windows Server 2008 R2 및 Ubuntu 14.04 환경을 대상으로 취약점 진단 및 모의침투를 수행한 프로젝트입니다.

공격자 관점에서 정보 수집(Reconnaissance), 취약점 분석(Vulnerability Assessment), 초기 침투(Initial Access), 권한 상승(Privilege Escalation), 포스트 익스플로잇(Post Exploitation)을 수행하여 실제 공격 가능성을 검증하였으며, 발견된 취약점에 대한 보안 대책을 수립하였습니다.

---

## 프로젝트 목표

* 취약점 진단 도구(OpenVAS, Nessus)를 활용한 보안 취약점 식별
* 실제 공격 시나리오 기반 모의침투 수행
* Windows 및 Linux 환경 권한 상승 검증
* 시스템 및 서비스 보안 설정 분석
* 보안 대책 수립 및 개선 방안 도출

---

## 진단 결과 요약

진단 결과 FTP, SMB, 웹 애플리케이션, 데이터베이스 및 원격 관리 서비스 등 다양한 서비스에서 정보 노출 및 원격 공격이 가능한 취약점이 확인되었습니다.

또한 공개된 취약점을 이용한 시스템 접근과 권한 획득이 가능하였으며, 취약한 계정 정책 및 과도한 권한 설정으로 인해 공격자가 관리자 권한을 획득할 수 있는 환경임을 확인하였습니다.

---

## 주요 발견 취약점

![주요 발견 취약점](../images/01_주요발견취약점.png)
| 구분         | 위험도      | 주요 내용                           |
| ---------- | -------- | ------------------------------- |
| 인증 및 접근 통제 | Critical | 취약한 계정 관리, Jenkins/Tomcat 익명 접근 |
| 시스템 보안     | High     | sudo NOPASSWD 설정, 불필요 서비스 활성화   |
| 정보 노출      | Medium   | DB 계정 정보 노출, 디렉터리 리스팅, 배너 정보 노출 |

## 핵심 공격 시나리오

### Windows 환경

#### 초기 침투

* MS17-010(EternalBlue) 취약점 악용
* Elasticsearch 취약점 분석
* Axis2 취약점 분석

#### 권한 획득

* Meterpreter 세션 확보
* SYSTEM 권한 확인
* NT AUTHORITY\SYSTEM 권한 획득

### Linux 환경

#### 초기 침투

* OpenVAS 기반 서비스 식별
* Apache Continuum 원격 코드 실행 취약점 악용

#### 내부 접근 및 권한 상승

* Reverse Shell 획득
* 데이터베이스 분석
* 계정 정보 확보
* sudo 설정 분석
* Root 권한 획득

### Post Exploitation

* 시스템 정보 수집
* 웹 서비스 분석
* 데이터베이스 분석
* 플래그 획득
* 중요 정보 수집

---

## 보안 대책 및 개선 방안

### 즉시 조치

* MS17-010 등 공개 취약점 패치 적용
* Apache Continuum 취약점 조치
* 불필요 서비스 비활성화
* 기본 계정 제거

### 단기 조치

* 최소 권한 원칙 적용
* 관리자 권한 재점검
* 관리자 페이지 접근 제한
* 중요 서비스 접근 통제 강화

### 장기 조치

* 정기 취약점 진단 수행
* 로그 모니터링 체계 구축
* 침해 대응 프로세스 수립
* 보안 정책 지속 개선

---

## 프로젝트 수행 소감

실제 침투 테스트 과정에서는 공개 취약점 자체보다 기본 계정 사용, 취약한 인증 정책, 패치 미적용과 같은 기본적인 보안 관리 미흡이 더 큰 위험 요소로 작용한다는 점을 확인할 수 있었습니다.

또한 OpenVAS, Nessus 등의 자동화 도구를 활용한 취약점 진단과 수동 검증을 병행하며 공격 가능성을 검증하였고, 침투 과정에서 발생한 다양한 오류를 분석하고 해결하며 문제 해결 능력과 트러블슈팅 역량을 향상시킬 수 있었습니다.
