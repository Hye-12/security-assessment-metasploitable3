# Metasploitable3 취약점 진단 및 침투 테스트 프로젝트

## 프로젝트 개요
Metasploitable3 Windows Server 2008 R2 및 Ubuntu 14.04 환경을 대상으로
공격자 관점의 취약점 진단 및 침투 테스트를 수행하였다.

## 실습 환경
- Kali Linux
- Metasploitable3 Windows
- Metasploitable3 Ubuntu
- VMware Workstation

## 사용 도구
- Nmap
- Metasploit Framework
- OpenVAS
- Nessus
- Wireshark

## 주요 수행 내용
- 네트워크 서비스 식별
- 취약점 분석
- 시스템 권한 획득
- 정보 수집
- 숨김 데이터 복구
- 보안 진단 보고서 작성

## 주요 결과
- MS17-010 취약점 분석
- Meterpreter 세션 획득
- MySQL Binary Log 분석
- DOCX 구조 분석
- Base64 인코딩 데이터 복구
- QR 코드 및 이미지 복원
