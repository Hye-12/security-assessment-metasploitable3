# 플래그 획득 (Flag Recovery)

## 개요

침투 및 권한 상승 이후 시스템 내부에 숨겨진 플래그(Flag)를 탐색하였습니다.

단순 파일 검색뿐 아니라 데이터베이스 분석, 로그 분석, 파일 포맷 분석 및 데이터 복구 기법을 활용하여 숨겨진 정보를 복원하고 플래그를 획득하였습니다.

---

## 획득 대상

| Flag | 획득 방식 |
|--------|--------|
| Queen of Hearts | MySQL Binary Log 분석 |
| Jack of Hearts | OOXML(.docx) 구조 분석 |
| Joker | Hex 데이터 복구 및 이미지 변환 |

---

## 수행 과정

### 1. 시스템 내부 정보 수집

- 사용자 디렉터리 탐색
- 웹 서비스 파일 분석
- 데이터베이스 분석
- 로그 파일 분석

### 2. 숨겨진 데이터 식별

- Binary Log 분석
- 문서 파일 구조 분석
- Hex 데이터 추출
- 이미지 복원

### 3. 플래그 복구

- 삭제 또는 은닉된 데이터 복원
- 인코딩 데이터 변환
- 파일 구조 분석
- 최종 플래그 획득

---

## 활용 기술

- MySQL Binary Log 분석
- OOXML 구조 분석
- Hex Encoding 분석
- PNG 파일 복원
- 데이터 복구 및 포렌식 기법

---

## 주요 성과

- 데이터베이스 로그 분석을 통한 정보 복구
- 문서 파일 내부 구조 분석
- Hex 데이터 변환을 통한 이미지 복원
- 다양한 분석 기법을 활용한 플래그 획득
