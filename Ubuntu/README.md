# Ubuntu 취약점 분석

## 개요

Metasploitable3 Ubuntu 14.04 환경을 대상으로 서비스 식별, 취약점 분석 및 공격 가능성 검증을 수행하였다.

진단 결과 ProFTPD, Samba, Apache Continuum, CUPS, MySQL, SSH 등 다양한 서비스에서 공개 취약점, 정보 노출 및 취약한 인증 정책이 확인되었다.

특히 Apache Continuum 원격 코드 실행 취약점을 이용하여 시스템 접근이 가능하였으며, 이후 데이터베이스 분석 및 계정 확보를 통해 추가적인 시스템 접근 가능성을 확인하였다.

# Ubuntu 취약점 분석

## 개요

Metasploitable3 Ubuntu 14.04 환경을 대상으로 서비스 식별, 취약점 분석 및 공격 가능성 검증을 수행하였다.

진단 결과 Apache Continuum, MySQL, OpenSSH, ProFTPD, Samba, CUPS 등 다양한 서비스에서 공개 취약점, 정보 노출 및 취약한 인증 정책이 확인되었다.

특히 Apache Continuum 원격 코드 실행 취약점을 이용하여 시스템 접근이 가능하였으며, 이후 데이터베이스 분석을 통해 계정 정보를 확보하고 SSH 접근 및 권한 상승까지 수행할 수 있음을 확인하였다.

## 문서 구성 안내

최종 보고서에서는 서비스별 취약점 진단 순서에 따라 정리하였으나, GitHub 포트폴리오에서는 실제 공격자가 시스템에 침투하는 흐름을 기준으로 재구성하였다.

Apache Continuum 취약점을 통한 초기 침투를 시작으로 데이터베이스 분석, 계정 확보, SSH 접근 및 권한 상승 과정까지 실제 공격 체인을 중심으로 정리하였다.

이를 통해 단순 취약점 나열이 아닌 실제 공격 과정과 문제 해결 흐름을 이해할 수 있도록 구성하였다.

## 요약

Ubuntu 환경에서는 Apache Continuum 취약점을 이용한 초기 침투 이후 데이터베이스 분석을 통해 계정 정보를 확보하고, 이를 기반으로 SSH 접근 및 권한 상승이 가능한 공격 체인을 확인하였다.

이번 진단을 통해 공개 취약점 관리뿐 아니라 계정 관리, 접근 통제, 최소 권한 원칙 적용의 중요성을 확인할 수 있었다.

또한 단일 취약점만으로 시스템이 침해되는 것이 아니라 정보 수집, 계정 확보, 내부 접근, 권한 상승이 연계되어 전체 시스템 장악으로 이어질 수 있음을 검증하였다.

## 요약

Ubuntu 환경에서는 Apache Continuum의 원격 코드 실행 취약점이 가장 위험도가 높은 취약점으로 확인되었다.

또한 데이터베이스 및 서비스 분석 과정에서 계정 정보 확보가 가능하였으며, 확보된 계정을 기반으로 시스템 내부 접근 및 권한 상승이 가능하였다.

이는 공개 취약점 관리뿐 아니라 계정 관리, 접근 통제, 최소 권한 원칙 적용이 중요함을 보여준다.
