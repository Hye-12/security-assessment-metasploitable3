# Apache Continuum 원격 코드 실행(RCE) 취약점 분석

## 개요

Apache Continuum은 소프트웨어 빌드 및 배포 자동화를 지원하는 지속적 통합(Continuous Integration) 서버이다.

진단 과정에서 Apache Continuum 서비스가 외부에 노출되어 있었으며, 공개된 취약점을 이용하여 원격 코드 실행(Remote Code Execution)이 가능한 환경임을 확인하였다.

본 취약점은 인증 없이 시스템 명령 실행이 가능하여 공격자가 서버에 대한 초기 접근 권한을 획득할 수 있는 심각한 취약점이다.

---

## 취약점 정보

| 항목  | 내용                |
| --- | ----------------- |
| 서비스 | Apache Continuum  |
| 포트  | 8080/TCP          |
| 유형  | 원격 코드 실행 (RCE)    |
| 위험도 | Critical          |
| 영향  | 시스템 접근 및 명령 실행 가능 |

---

## 서비스 식별

Nmap 및 웹 서비스 분석을 통해 Apache Continuum 서비스가 동작 중임을 확인하였다.

### 확인 내용

* Apache Continuum 서비스 활성화
* 웹 인터페이스 접근 가능
* 버전 정보 확인

---

## 취약점 확인

공개 취약점 조사 결과 Apache Continuum에서 원격 코드 실행이 가능한 취약점이 존재함을 확인하였다.

해당 취약점은 서버에서 사용자 입력을 적절히 검증하지 않아 공격자가 임의 명령을 실행할 수 있는 문제이다.

---

## 공격 가능성 분석

공격자는 조작된 요청을 통해 서버에서 임의 명령을 실행할 수 있다.

이를 통해 다음과 같은 행위가 가능하다.

* 시스템 정보 수집
* 계정 정보 확인
* Reverse Shell 생성
* 내부 네트워크 탐색
* 추가 권한 상승 시도

본 프로젝트에서는 실제 검증 과정에서 Reverse Shell 획득에 성공하여 시스템 접근 가능성을 확인하였다.

※ 상세 공격 과정은 `05_초기침투/Ubuntu` 문서에서 설명한다.
