
# 정보 수집 및 분석 (Post Exploitation)

## 개요

초기 침투 및 권한 상승 이후 시스템 내부 정보 수집과 분석을 수행하였습니다.

운영체제, 사용자 계정, 데이터베이스, 웹 서비스 및 로그 파일을 분석하여 추가적인 공격 경로와 중요 정보를 식별하였으며, 숨겨진 데이터와 플래그(Flag)를 탐색하였습니다.

---

## 수행 절차

1단계. 시스템 접근
2단계. 사용자 및 권한 정보 확인
3단계. 서비스 및 설정 파일 분석
4단계. 데이터베이스 분석
5단계. 로그 분석
6단계. 중요 정보 수집

---

## 시스템 정보 수집

### Windows

- 사용자 계정 확인
- 서비스 정보 확인
- 실행 프로세스 분석
- 공유 자원 확인

### Ubuntu

- 사용자 및 그룹 확인
- 서비스 설정 분석
- 웹 서비스 구조 확인
- 중요 파일 탐색

---

## 데이터베이스 분석

### MySQL

- 데이터베이스 목록 확인
- 테이블 구조 분석
- 계정 정보 확인
- 서비스 연관 데이터 분석

### 주요 결과

- 계정 정보 확보
- 서비스 설정 정보 확인
- 추가 접근 경로 확보

---

## 로그 분석

### 수행 내용

- 시스템 로그 분석
- 서비스 로그 분석
- MySQL Binary Log 분석
- 사용자 활동 내역 확인

### 주요 결과

- 숨겨진 데이터 복구
- 삭제된 정보 확인
- 플래그 획득 단서 확보
